# 墨屿 MOYU

面向中文创作者的桌面写作软件，让故事有处栖身。

当前版本：**MOYU Beta 1 · v0.9.0-beta.1**。支持 **Windows 10/11 x64**。

墨屿当前为闭源软件，源码目前未公开。此公开仓库仅用于版本发布、软件下载与问题反馈。版权所有，保留所有权利；不提供开源许可。

## 下载与安装

- [GitHub 发行版](https://github.com/ltfxhxh/moyu-releases/releases/tag/v0.9.0-beta.1)
- [AtomGit / GitCode 分发仓库](https://gitcode.com/lvtengfei/moyu-releases)

下载 `MOYU-0.9.0-beta.1-win-x64.exe`，运行安装程序即可。无需安装 Node、npm、Python 或开发工具。发行版同时提供 `SHA256SUMS.txt` 供校验文件完整性。

## 写作与故事管理

- 书库与写作空间，卷章管理，中文输入与 Microsoft Pinyin 支持。
- 人物、关系、故事线与伏笔管理；写作上下文与故事轨迹帮助保持创作连贯。
- 视觉工作室、作品视觉身份、人物形象、插画与封面。
- 章节画境、静幕与破境入境，以及作品自己的入境音乐。
- 自动保存、恢复与 `.moyu` 备份。

AI 不代写小说正文。可选视觉能力使用生成模型；可在墨屿设置中配置凭据，不配置也能正常写作。

## 数据安全

**当前为 Beta 测试版本。重要作品请保留独立的 `.moyu` 备份，并将备份存放在其他位置。**

作品保存在本机。视觉生成由作者主动发起，相关叙事上下文与参考素材会发送给所选视觉服务。墨屿没有遥测、统计分析、自动崩溃上传或自动正文上传。

可通过 Windows「设置 → 应用」卸载。普通卸载保留作品；可选择清理本机数据与设置，作品目录和 `.moyu` 备份仍保留。
